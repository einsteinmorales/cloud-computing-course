# Cloud Concepts Reflection


I use cloud computing almost every day whether for communicating with friends and family, 
making online payments, or watching movies and TV shows. Some of the cloud services I use 
most often are Facebook Messenger, GCash, and Netflix.


**Facebook Messenger** falls under *Software as a Service (SaaS)*. It lets users send messages, 
make voice and video calls, and share media over the internet — with no need to set up or
maintain any hardware or software themselves. It follows the Public Cloud deployment model, 
since anyone with a Meta account can access it from any connected device.

**GCash** is also an example of *SaaS*: it delivers digital payments and financial services directly
through a mobile app, so users don’t have to manage any backend systems. It runs on the Public 
Cloud, allowing customers to securely access their accounts and complete transactions from anywhere
with an internet connection.

**Netflix** is another *SaaS* offering — it streams video content straight to subscribers, with no need 
for users to install, update, or manage streaming servers. It is classified as a Public Cloud 
service because it is available globally to millions of people over the internet.

Git and GitHub are vital tools for cloud-based development work. They provide version control, 
keeping a full record of every change made to files and configurations — so earlier versions can 
be restored easily if errors occur. GitHub also supports smooth teamwork: using branches and pull 
requests keeps work organized, reduces conflicting changes, and lets teams review updates before 
they are added to the main project. This helps catch problems early and keeps cloud applications
reliable and high-quality.

Through this activity, I realized that cloud computing is already deeply integrated into my daily 
life. Services like Messenger, GCash, and Netflix make communication, finance, and entertainment 
far more convenient. I also learned that Git and GitHub are essential for effective collaboration, 
change tracking, and reliable management of cloud projects.
